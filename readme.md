# UC16: Sort Bogie Capacities (Bubble Sort)
## Goal
Manually sort capacities using Bubble Sort.
## Actor
User
## Flow

Create array
Compare adjacent values
Swap when required
Repeat until sorted
Display final result

## Key Concepts Used

Bubble Sort
Nested loops
Swapping logic

## Key Requirements

No Arrays.sort(), no Collections.sort()

## Key Benefits

Teaches algorithmic fundamentals
