# UC2: Add Passenger Bogies to Train (ArrayList Operations)
## Drawback of UC1
No ability to add/remove bogies.
## Goal
Allow dynamic insertion and removal of passenger bogies using ArrayList.
## Actor
User
## Flow
User runs program
Passenger bogies added
Bogies displayed
Bogie removed
Existence checked
Program continues

## Key Concepts Used
ArrayList
add(), remove(), contains()
CRUD operations
Insertion order preservation

## Key Requirements
Create ArrayList<String>
Add Sleeper, AC Chair, First Class
Remove AC Chair
Check if Sleeper exists
Display final list

## Key Benefits
Demonstrates list management
CRUD on collections
Visualizes attachment/detachment
