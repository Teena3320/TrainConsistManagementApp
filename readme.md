Preserve sequence and support fast insert/remove.
## Actor
User
## Flow

Insert Pantry Car in middle

addFirst(), addLast(), removeFirst(), removeLast()
Node structure concept
Order preservation

Create LinkedList
Add Engine, Sleeper, AC, Cargo, Guard
